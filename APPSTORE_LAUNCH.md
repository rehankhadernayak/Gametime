## Screenshots Design Guidelines

### Device Resolutions

| Platform | Dimensions | Format | Notes |
|----------|-----------|--------|-------|
| iOS | 1242×2208 | PNG | 6 images max |
| Android | 1080×1920 or 1440×2560 | PNG | 2–8 images |
| Web | 1920×1080 | JPG/PNG | Marketing site |

### Text Overlay Tips
- Use bold sans-serif (Nunito)
- High contrast: white text on dark gradient
- Keep key UI elements visible
- Show navigation at bottom
- Highlight primary action buttons

### Color Palette
- Primary: Indigo (#3B5BDB)
- Secondary: Purple (#7C3AED)
- Accent: Gold (#FFB800) for rewards
- Background: Dark navy (#0F172A)
- Text: White (#FFFFFF)

## Troubleshooting Rejections

### Common iOS Rejections
- **"Needs age-appropriate content rating"** → Verify content rating questionnaire
- **"Requires parental consent language"** → Add clear parental consent in Terms
- **"Guideline 1.3 — Business Model Confused"** → Clarify free gameplay, optional purchases
- **"Guideline 3.1.1 — In-App Purchase"** → Verify GP topup pricing is clear

### Common Android Rejections
- **"Inadequate privacy policy"** → Reference COPPA/PDPA compliance
- **"Fails security tests"** → Ensure API uses HTTPS, JWT validated
- **"Misleading description"** → Keep description factual, feature-accurate
